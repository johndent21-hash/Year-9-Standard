In this chapter you will

  • find the length, midpoint and gradient of an interval on the number plane
  • graph straight lines from a table of values, from intercepts and from y = mx + c
  • find the equation of a straight line from its graph or from two points
  • solve linear equations by reading a graph
  • use straight-line graphs and equations to model real situations
  • graph parabolas and use them in real situations

About the artwork

The pictures in this booklet are parts of the Mandelbrot set, drawn by a computer that repeats one simple rule, z → z² + c, thousands of times for every point. Every booklet shows a different part of the set: this one is silver seahorse tails deep in Seahorse Valley, coloured in purple and silver. Maths can make beautiful things.

NOTESKey ideas for this lessonTeacher copy

Key terms

midpoint (M)
the point halfway along an interval
average
add, then divide by how many
endpoints
A(x₁, y₁) and B(x₂, y₂)

Formulas

  • M = ((x₁ + x₂) ÷ 2, (y₁ + y₂) ÷ 2)
  • x of M = average of the x-values
  • y of M = average of the y-values
  • Endpoint: B = 2 × M − A (for x and y)

Steps 1 add the x-values, ÷ 2 2 add the y-values, ÷ 2 3 write M as a point (x, y)

Easy
Learning intention

We are learning to find the gradient (steepness) of an interval or a line.

Success criteria
  • I can say whether a gradient is positive, negative, zero or undefined
  • I can find a gradient by counting rise and run on a grid
  • I can use the gradient formula with any two points
NOTESKey ideas for this lessonTeacher copy

Key terms

gradient (m)
the steepness of a line: rise ÷ run
rise
change in y: up +, down −
run
change in x, left to right
positive
goes up to the right
negative
goes down to the right
zero
horizontal line
undefined
vertical line (run = 0)

Formulas

  • m = rise ÷ run
  • m = (y₂−y₁) ÷ (x₂−x₁)
  • Horizontal: m = 0
  • Vertical: m is undefined

Steps 1 pick two points on the line 2 count the run (to the right) 3 count the rise (up + or down −) 4 m = rise ÷ run, simplified

Learning intention

We are learning to use parabolas to model real situations, such as falling objects and arches.

Success criteria
  • I can complete a table of values for a quadratic model
  • I can read values from the graph of a model
  • I can find the start, the highest point and when the model reaches a value
NOTESKey ideas for this lessonTeacher copy

Key terms

model
an equation that describes a real situation
y-intercept
the starting value (t = 0)
vertex
the highest or lowest point
x-intercepts
where the height is 0 (on the ground)
sensible values
only the times or lengths that make sense, e.g. t ≥ 0

Formulas

  • Falling stone: h = −5t² + c (c = starting height)
  • Start: put t = 0
  • On the ground: put h = 0 and solve
  • Area of a square: A = x²
